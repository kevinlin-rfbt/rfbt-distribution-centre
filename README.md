# RFBT Distribution Centre

Responsive static homepage and Accessibility page. All ordering and customer sign-in links use Lilypad. Four original accessibility PDFs are included, with View and Download controls. Questions and accessible-format requests use accessibility@rfbtdistributioncentre.com.

Edit `build-pages.mjs` then run `node build-pages.mjs` to regenerate the HTML. Edit `dist/styles.css` for visual changes. The `dist/` folder works on GitHub Pages or any static host. All paths are relative so repository subpaths work.

For GitHub Pages, push to a new repository under the confirmed company account. Select GitHub Actions as the Pages source; the included workflow publishes `dist/`. The GitHub account/repository has not been connected in this chat. No DNS or live-domain changes are included.

The original supplied logo and PDFs are preserved. The hero is illustrative generated photography; category graphics are SVG illustrations. The fourth PDF retains its Draft label. Accessibility features include semantic landmarks, skip navigation, visible focus, keyboard mobile navigation, reduced-motion support and descriptive PDF links. No full accessibility certification is implied.
